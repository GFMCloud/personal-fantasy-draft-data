# Research: published draft-tool methods and free data sources

Deep-research sweep run 2026-08-26 (background agent, 39 sources, live-verified the
key endpoints). Basis for Amendment 1 in `design.md`.

## 1. Pick-survival models, P(player available at pick N)

- **Normal CDF on ADP** (the standard): P(available at n) = 1 − NormCDF(n; ADP, sd).
  Originated with Jeff Zimmerman (RotoGraphs 2017); clearest modern writeup is
  DraftKick. Needs ADP mean + sd; when sd is missing, ADP/4 is the common
  approximation. Known weakness: pick ranges tighten early and widen late, so a
  global sd rule is wrong in the tails.
  https://draftkick.com/blog/projected-availability/
- **Expected value of next pick** (probabilistic VBD, Fantasy Draft Coach): per
  position, sum projection × P(best available at your pick) = value of waiting.
  Bridges survival probabilities to VONA. https://www.fantasydraftcoach.com/
- **Empirical availability from pick logs**: joewlos's simulator fits a logistic
  regression on real pick-level draft data instead of assuming normality.
  https://github.com/joewlos/fantasy_football_monte_carlo_draft_simulator
- Academic: Becker & Sun robust-optimization draft/lineup paper
  (https://www.researchgate.net/publication/289801869); descriptive snake-draft
  study (https://sjdm.org/~baron/journal/22/220318/jdm220318.html).
- **Input takeaway**: ADP mean + sd per format (planned via FFC) covers the standard
  methods; empirical pick logs correct the normal assumption where it is worst,
  which is the round-2/3 zone containing picks 24/25.

## 2. Distributional / pick-level ADP, free

- FFC API returns more than mean+sd (verified live): `adp, stdev, high, low,
  times_drafted, bye` per player plus `total_drafts, start_date, end_date` meta.
  Daily updates, trailing ~7-day window, free with attribution.
  https://help.fantasyfootballcalculator.com/article/42-adp-rest-api
- FFC completed mock boards are free pick-level logs (verified): index at
  `/mock-draft/results/format/{fmt}/teams/all`, full pick-by-pick boards at
  `/draft/{id}`. A few hundred boards yield an empirical pick distribution and
  opponent-model training data.
- Sleeper `GET /v1/draft/<id>/picks` returns full pick logs, no key, but only for
  drafts whose IDs you know (your own leagues). https://docs.sleeper.com/
- No free percentile-ADP source exists; FFC high/low + scraped boards is the ceiling.

## 3. Tier clustering

- Boris Chen: R `mclust` Gaussian mixture over FantasyPros ECR. His pipeline now
  needs a FantasyPros key (https://github.com/borisachen/fftiers), but his **output
  is free and machine-readable** (verified):
  `https://s3-us-west-1.amazonaws.com/fftiers/out/weekly-ALL-PPR.csv` with
  Rank, Tier, Best/Worst/Avg rank, sd, ~200 players; other formats in same bucket.
- **DynastyProcess data repo** republishes FantasyPros ECR (`ecr, sd, best, worst`)
  with platform IDs, weekly GitHub Actions refresh, GPL-3. Strongest free input for
  running our own GMM. https://github.com/dynastyprocess/data ;
  https://nflreadr.nflverse.com/reference/load_ff_rankings.html
- Extension: Scott Rome's GMM on (projection, rank) with manual tier count.
  https://srome.github.io/Extending-the-Gaussian-Mixture-Approach-To-Fantasy-Football-Tiering/
- Fallback: GMM directly on FFC ADP+sd; k-means/Jenks lose per-player uncertainty.

## 4. VORP / replacement-level variants

- Definitions VOLS / VORP / VONA: FantasyPros glossary
  (https://support.fantasypros.com/hc/en-us/articles/115005868747) and strategy piece
  (https://www.fantasypros.com/2025/06/fantasy-football-draft-strategy-value-based-drafting-vorp-vols-vona/).
- Subvertadown baseline guide: BEER/BEER+ adjust replacement level for historical
  games-missed per position; needs games-played history, derivable from nflverse
  weekly data. https://subvertadown.com/article/guide-to-understanding-the-different-baselines-in-value-based-drafting-vbd-vols-vs-vorp-vs-man-games-and-beer-
- FFA: VOR with uncertainty from multi-analyst projection spread.
  https://fantasyfootballanalytics.net/2024/08/winning-fantasy-football-with-projections-value-over-replacement-and-value-based-drafting.html
- All variants need only projections/ranks, roster config, and (VONA) the survival
  model. Nothing paid.

## 5. Open-source snake-draft simulators

- joewlos (FastAPI, logistic-regression opponent model from Sleeper logs):
  https://github.com/joewlos/fantasy_football_monte_carlo_draft_simulator
- dlm1223 (R, linear optimization under ADP-availability constraints, positional
  projection-error distributions): https://github.com/dlm1223/fantasy-football
- alexwaldrop (MCMC tree search): https://github.com/alexwaldrop/fantasy_draft_tools ;
  cdtdev (simple Python MC): https://github.com/cdtdev/ff_monte_carlo
- ffverse `ffsimulator` simulates seasons, not drafts; useful post-draft validation
  pattern. https://ffsimulator.ffverse.com/reference/ffs_latest_rankings.html
- Common input pattern: (ADP mean, ADP sd, projections); better ones add pick logs.

## 6. Additional free sources evaluated

In (see Amendment 1): DynastyProcess ECR + ID crosswalk, Boris Chen tier CSVs,
Sleeper trending adds, nflverse draft capital, ffopportunity xFP
(https://nflreadr.nflverse.com/reference/load_ff_opportunity.html).

Out: Underdog CSV (login-gated, best-ball skew), Vegas win totals (nfl_data_py feed
verified dead after 2020; The Odds API needs a key for marginal value), FantasyPros
HTML scraping (DynastyProcess republishes cleanly), MFL ADP (redundant), per-player
K/DST stats (team-level rows suffice), cloning fftiers (needs FantasyPros key).

## 7. Pipeline pitfalls (informing validation and schema)

- ADP staleness: FFC window is trailing ~7 days, updated daily; camp news moves
  markets in 24–72 h. Store snapshot metadata; re-pull morning of draft.
- Format mismatch: best-ball/keeper/2QB ADP silently distorts redraft boards.
- Names are not keys: suffixes, punctuation, duplicates; crosswalks decay in-season.
  Use maintained crosswalks (`load_ff_playerids`); Harris (names only) is the
  riskiest merge. https://fantasyplayerdatabase.com/player-id-systems-and-cross-platform-matching
- K/DST: no gsis id for DST, inconsistent naming; model as team-level rows.
- Silent absence: FFC omits deep players entirely; absence is NA, never "last pick";
  keep `times_drafted`.
